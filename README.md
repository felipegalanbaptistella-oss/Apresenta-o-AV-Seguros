# Apresentação AV — Gestão de Riscos

Este repositório contém o pacote do cliente web da apresentação de Gestão de Riscos, incluindo os assets e bundles JavaScript enviados.

## Conteúdo

- `dist/client/`: arquivos compilados da aplicação web e recursos usados pelo gerador de apresentação.
- `dist/client/legacy.html`: versão HTML legada incluída no pacote de deploy.

O código-fonte original do projeto não estava nos arquivos enviados; para continuar o desenvolvimento é necessário recuperar a pasta fonte usada para gerar este build.
